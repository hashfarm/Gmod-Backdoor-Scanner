# Test cases for composite_rules.txt, executed by the self-check and by CI.
#
# Two forms:
#
#   + COMP-002 ;;; <lua snippet>        scanned for real, then the file-level
#   - COMP-002 ;;; <lua snippet>        composites are evaluated on what it found
#
#   + COMP-010 ;;; ids: LUA-008, BIN-014    the expression is evaluated directly
#   - COMP-010 ;;; ids: LUA-008             against that set of pattern ids
#
# Scan-level rules (those written with a `scan:` prefix) span several files, so
# they are tested with the `ids:` form. Every rule needs at least one + and one -.
