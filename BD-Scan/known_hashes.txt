# SHA-256 hashes of files known to be backdoors. One per line; anything after
# ;;; on the same line is a note and is ignored by the scanner.
#
# A hash list is only worth as much as its provenance. Everything below comes
# from one source, named per entry, where somebody caught the file on a real
# server and wrote down what it did. Nothing here is included on the strength
# of a rumour, and nothing was added just because a scanner disliked it.
#
# Source: https://github.com/BannedGithub/Backdoor_Busting_2015
#         commit e6df2783cbac9ce95e53b0511aa68eb76358ee32
#         A labelled database of Garry's Mod backdoors found between 2015 and
#         2016, each family with a note on what it did. The scanner's own
#         malicious corpus test scans the same files; see
#         tests/malicious_corpus.sh. That test ignores hash matches on purpose,
#         so the recall it reports measures the pattern rules, not this list.
#
# These are old. They catch the copy that is still being passed around, which
# does happen -- backdoored addon packs get re-uploaded for years. They will not
# catch a variant, and they are not a substitute for the rules. A hash is of the
# file exactly as it sits on disk, so any edit at all produces a different one.
#
# Some entries are a deobfuscated copy an analyst produced next to the original.
# Those are listed too: a decoded payload sitting in an addons folder is not
# better news than the encoded one.
#
# To add your own:
#
#   - Files you have personally confirmed on a server you administer. Every
#     entry in scan_log.json carries a "hash" field holding the SHA-256 of the
#     file the finding came from, so once you have confirmed a file, its hash is
#     already in the report you were reading:
#
#       python -c "import json; log = json.load(open('scan_log.json')); \
#         [print(h) for h in sorted({d['hash'] for d in log['detections'] if d.get('hash')})]"
#
#     Add only the hashes of files you actually looked at.
#   - A hash list published by a community you have reason to trust, ideally
#     one that says where each entry came from.
#
# Format:
#   <64 hex characters>
#   <64 hex characters>;;;where this one came from
