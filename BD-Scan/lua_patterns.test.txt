# Test cases for lua_patterns.txt, executed by the self-check and by CI.
#
# Format:  + <ID> ;;; <lua snippet>     the snippet MUST produce that detection
#          - <ID> ;;; <lua snippet>     the snippet MUST NOT produce it
#
# \n in a snippet becomes a newline. Snippets run through the real scanner, so
# comment stripping and literal folding are exercised too.
#
# Every pattern needs at least one + and one - case. A new pattern without both
# fails the self-check.
